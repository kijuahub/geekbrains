# Список дел TODO-List

Добро пожаловать в минималистичное и удобное веб-приложение для управления повседневными задачами! 

Это приложение создано для того, чтобы помочь вам легко организовывать свои дела. Оно имеет красивый и современный интерфейс

---

## Стек программы
* Python
* Flask
* Flask SQLAlchemy для работы с базой данных

## Как пользоваться приложением

Все ваши задачи разделены на три удобных списка, чтобы ничего не потерялось и не путалось перед глазами.

### 1. Добавление новых задач
В самом верху приложения находится поле ввода. 
* Просто кликните по тексту **«Введите задачу»**, напишите то, что вам нужно сделать (например, «Купить молоко» или «Закончить отчет»), и нажмите кнопку **«Добавить»** (или клавишу Enter). 
* Ваша задача плавно появится в разделе **«Активные»**.

### 2. Выполнение задач
Раздел **«Активные»** — это ваш основной фронт работ. 
* Слева от каждой активной задачи есть круглый чекбокс. 
* Как только вы справились с делом, просто кликните на этот чекбокс.
* Задача будет красиво зачеркнута и автоматически «улетит» вниз, в список **«Выполненные»**, чтобы не отвлекать вас от оставшихся дел.
* *Случайно нажали?* Не беда! Кликните по галочке в списке выполненных, и задача вернется обратно наверх.

### 3. Удаление задач (Корзина)
Если задача стала неактуальной, вы можете нажать красную кнопку **«Удалить»** справа от неё.
* Не волнуйтесь, задача не исчезнет безвозвратно! Она переместится в самый нижний раздел — **«Недавно удаленные»** (это работает как корзина на вашем компьютере).

### 4. Восстановление и очистка корзины
В разделе **«Недавно удаленные»** хранятся все ваши отмененные дела. У каждой задачи здесь есть две опции:
* 🟢 **«Восстановить»**: вернет задачу обратно в список активных дел, если вы передумали.
* 🔴 **«Навсегда»**: полностью и безвозвратно удалит задачу из системы. Используйте это, чтобы очистить список от скопившегося мусора.
